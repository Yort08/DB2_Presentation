Processes Used to Clean the Data

🔍 Explicit Missing Value (NaN)

Audited via df.isnull().sum().

Identified 1 explicit NaN in Caffeine (mg) at Row 158 (Iced Black Tea Chai Latte).

🔍 Implicit Text Placeholders ("Varies")

Audited string entries.

Discovered 22 rows with string placeholders "Varies" (13) and "varies" (9) in Caffeine (mg).

🔍 Typographical Format Error in Total Fat (g)

Row 237 contained string '3 2' (space entered instead of decimal point .). This caused Pandas to read the entire column as object text.

Fix Applied: Replaced '3 2' with '3.2' and converted column to numerical float64.

🔍 Duplicate Row & Recipe Check

Ran df.duplicated().sum() → 0 exact duplicate rows.

Verified recipe combinations of (Beverage_category, Beverage, Beverage_prep). Confirmed all 242 rows represent distinct valid menu items.

🔍 Whitespace Pollution Removal

Column headers contained irregular padding spaces (e.g. ' Total Fat (g)').

Fix Applied: Executed df.columns = df.columns.str.strip() and trimmed all categorical string columns.

# Applied Data Cleaning Pipeline Code
# 1. Clean Column Headers
df.columns = df.columns.str.strip()

# 2. Trim string whitespace in text columns
for col in df.select_dtypes(include=['object', 'string']).columns:
    df[col] = df[col].astype(str).str.strip()

# 3. Correct typo '3 2' -> '3.2' in Total Fat (g) and convert to float
df['Total Fat (g)'] = df['Total Fat (g)'].str.replace('3 2', '3.2').astype(float)

# 4. Coerce text 'Varies' / 'varies' in Caffeine (mg) to numeric NaN
df['Caffeine (mg)'] = pd.to_numeric(df['Caffeine (mg)'], errors='coerce')

# 5. Fill Missing Numerical Values Using Category Median
